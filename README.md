Amigo Screto
Es mi primer proyecto desarrollado como parte del challenger de Oracle. Permite a los usuarios ingresar nombres de amigos y realizar un sorteo aleatorio.

## Funcionalidades

**Agregar nombres:** Escribe un nombre y agrégalo a la lista con un botón.  
**Validación:** Evita agregar nombres vacíos.  
**Lista de amigos:** Muestra todos los nombres ingresados.  
**Sorteo aleatorio:** Selecciona un nombre de la lista al presionar "Sortear amigo".  


## Cómo usarlo

1. Ingresa un nombre en el campo de texto.  
2. Presiona **"Añadir"** para guardarlo en la lista.  
3. Cuando hayas agregado todos los nombres, presiona **"Sortear amigo"**.  
4. Se mostrará un nombre aleatorio como resultado.
